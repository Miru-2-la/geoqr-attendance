Three tables, and the database only guards one of the links

The MySQL schema Hibernate builds from the entity classes. The solid line is a real foreign key. The dashed lines are plain id columns that the database does not check.

PK primary key FK enforced foreign key ref reference with no constraint Hover a row to see which column it connects to.

How the tables work together

  • users holds admins and students in one table. The role column says which, and admin_code or roll_number is filled in for that role only.
  • events is created by an admin (created_by) and stores the geo-fence: latitude, longitude and radius_meters.
  • attendance is one row per successful scan, with the device and the measured distance.
